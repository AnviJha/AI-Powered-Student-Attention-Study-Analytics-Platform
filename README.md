# AI-Powered Student Attention & Study Analytics Platform

This repository contains the Phase 1 presentation frontend and its project documentation.

## Run the UI

Requires Node.js and npm. Run `npm install`, then `npm run dev` and open the local URL shown by Vite. Use `npm run build` to create a production build in `dist/`.

The app is a React, Tailwind CSS, and Recharts demo. All metrics and recommendations come from `src/data.js`. Session controls, challenges, goals, and settings use local page state and reset on reload. No backend or camera access is required.

## Immediate objective

**Build and present the complete frontend UI only.** The upcoming presentation needs a convincing, navigable UI demonstration. The current phase does not require a working backend, real webcam analysis, machine learning, or live GenAI.

Use realistic mock data and local frontend state to demonstrate the intended experience. Label simulated values clearly where needed; do not claim that unimplemented AI capabilities are operational.

## Product positioning

A privacy-first study companion that turns observable study-session signals and study history into understandable attention estimates, study analytics, and personalized guidance.

The platform estimates attention from observable behavior. It cannot directly measure a student's mental state or prove that the student is cognitively focused.

## Current implementation status

The repository initially contained documentation only. Phase 1 now includes the frontend presentation demo. Later phases remain unimplemented.
